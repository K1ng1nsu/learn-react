### What is Ref
const playerName = useRef();

useRef 는 항상 current 속성을 가지고 있는 객체를 리턴한다.
연결한 DOM(html 엘리먼트에 ref 속성으로 연결)에 current 속성으로 접근할 수 있다.

<input ref={playerName} type="text" />

playerName.current // input element

### When use Refs

-DOM 요소에 접근: 특정 DOM 요소에 직접 접근할 필요가 있을 때.
-값을 저장: 컴포넌트가 리렌더링되어도 값이 유지되어야 할 때.
-렌더링 사이드 이펙트 방지: 불필요한 리렌더링 없이 값을 참조해야 할 때.
-포커스 관리: 입력 필드에 포커스를 설정하거나 관리할 때.

# State vs Refs
State
- 값이 바뀔 때 마다 컴포넌트를 재평가받게 함
- UI에 직접적(바로) 반영되어야 하는 경우 사용할 것
- UI에 직접적(바로) 반영되어야 하는 경우(behind the scenes)가 아니면 사용하지 말 것

Refs
- 값이 바뀌어도 컴포넌트가 재평가 받지 않음
- DOM에 직접 접근해야할 때 사용할 수 있음 (돔에서 값을 읽어오거나, 브라우저 API에 접근할 때 사용하면 좋음)
- 한 파일안 이면서, 컴포넌트 밖에 작성된 코드는 모든 인스턴스가 공유함
- 컴포넌트의 인스턴스가 각각 가져야 하는 변수(컴포넌트가 재 평가받아도 값을 유지해야 하지만, UI에 영향을 주지않는 변수)( dom에 연결하지않은 ref의 current에 값을 저장) 
- ref를 prop으로 전달하는건 리액트19 부터고 그 전에는 forwardRef를 통해 전달해야한다
